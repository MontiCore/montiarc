# Language Server for MontiArc + CD4C
To start IntelliJ with the generated plugin, you can execute the gradle task 
`runMontiArcWithCDIntellijPluginAttached`. This task opens the `./example` project. 
The language server can be debugged by running 
`runMontiArcWithCDIntellijPluginAttached` with a debugger attached.

## Installing the packaged plugin
See install instructions in the documentation:
https://monticore.github.io/montiarc/v7.10/GettingStarted/Editor/
